# แผนที่ฝนและพื้นที่ต่ำของไทย

เว็บทดลองสำหรับดูข้อมูลฝนรายพื้นที่ ความสูงภูมิประเทศ และสถานการณ์น้ำขังตามสมมติฐาน

## วิธีใช้

เปิดเว็บ เลือกพื้นที่ในรายการหรือแตะจุดบนแผนที่เพื่อดูค่าฝนย้อนหลังจากแบบจำลองอากาศ ฝนคาดการณ์ 24 ชั่วโมง และช่วงน้ำขังจำลอง เลื่อนระดับน้ำเพื่อสำรวจพื้นที่ที่พื้นดินต่ำกว่าระดับน้ำสมมติ

## ข้อจำกัด

ค่าฝนมาจากแบบจำลองอากาศของ [Open-Meteo](https://open-meteo.com/en/docs) ไม่ใช่การตรวจวัดที่สถานีในทุกจุด สูตรน้ำขังใช้สมมติฐานว่าระบายน้ำได้ 30 มม./วัน และ **ไม่ใช่การพยากรณ์ระดับน้ำท่วมจริง** ยังไม่รวมระดับน้ำในแม่น้ำ ทางไหล คันกั้นน้ำ หรือระบบระบายน้ำในพื้นที่ ห้ามใช้เพื่อการตัดสินใจด้านความปลอดภัย

ข้อมูลความสูงจาก [AWS Terrain Tiles](https://registry.opendata.aws/terrain-tiles/) แผนที่ฐานจาก Esri และแสดงแผนที่ด้วย Leaflet

## การเผยแพร่

โครงการนี้เป็น HTML แบบไฟล์เดียว พร้อม Vercel Functions ใน `api/` สำหรับส่งข้อมูลแผนที่และฝนผ่านโดเมนเดียวกับเว็บ ไม่ต้องตั้งค่า API key
