# แผนที่ฝนและพื้นที่ต่ำของไทย

เว็บทดลองสำหรับดูฝนตรวจวัดจากสถานีกรมอุตุนิยมวิทยา ฝนคาดการณ์รายพื้นที่ ความสูงภูมิประเทศ และสถานการณ์น้ำขังตามสมมติฐาน

## วิธีใช้

เปิดเว็บเพื่อดูฝนตรวจวัด 24 ชั่วโมง ณ เวลา 07:00 น. จากสถานีกรมอุตุนิยมวิทยาที่ใกล้แต่ละพื้นที่ พร้อมชื่อสถานีและระยะห่าง กด “จำลอง” เพื่อดูฝนย้อนหลังและฝนคาดการณ์จาก Open-Meteo กับช่วงน้ำขังตามสมมติฐาน เลื่อนระดับน้ำเพื่อสำรวจพื้นที่ที่พื้นดินต่ำกว่าระดับน้ำสมมติ

กด “ดูระดับน้ำตรวจวัดใกล้จุดที่เลือก” ใต้สไลด์เพื่อดูระดับน้ำจากสถานีโทรมาตร [สสน.](https://data.go.th/en/dataset/water-level) ที่อยู่ภายใน 50 กม. และมีข้อมูลไม่เกิน 6 ชั่วโมง ค่าแสดงเป็นเมตรเทียบระดับทะเลปานกลาง พร้อมชื่อสถานี ระยะห่าง และเวลา ค่าสถานีไม่เปลี่ยนสไลด์หรือชั้นสีบนแผนที่ เพราะระดับน้ำในแม่น้ำจุดหนึ่งใช้แทนระดับน้ำท่วมทั่วพื้นที่ไม่ได้

## ข้อจำกัด

ข้อมูลตรวจวัดจาก [กรมอุตุนิยมวิทยา](https://data.go.th/th/dataset/c1-1-3-4) รายงานวันละครั้ง และเป็นค่าที่สถานี ไม่ใช่ฝน ณ พิกัดที่เลือกแบบทันที โหมดจำลองใช้แบบจำลองอากาศของ [Open-Meteo](https://open-meteo.com/en/docs) สูตรน้ำขังใช้สมมติฐานว่าระบายน้ำได้ 30 มม./วัน และ **ไม่ใช่การพยากรณ์ระดับน้ำท่วมจริง** ยังไม่รวมระดับน้ำในแม่น้ำ ทางไหล คันกั้นน้ำ หรือระบบระบายน้ำในพื้นที่ ห้ามใช้เพื่อการตัดสินใจด้านความปลอดภัย

ข้อมูลความสูงจาก [AWS Terrain Tiles](https://registry.opendata.aws/terrain-tiles/) แผนที่ฐานจาก Esri และแสดงแผนที่ด้วย Leaflet

## การเผยแพร่

โครงการนี้เป็น HTML แบบไฟล์เดียว พร้อม Vercel Functions ใน `api/` สำหรับส่งข้อมูลแผนที่และฝนผ่านโดเมนเดียวกับเว็บ ไม่ต้องตั้งค่า API key
